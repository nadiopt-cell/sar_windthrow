# GeoPackage детекций coh_delta — 12 проверенных участков

Дата сборки: 05.09.2026. Источник: `gfw_rescore.py` (детектор плагина v1.0, режим coh_delta, HyP3 INSAR-GAMMA, сетка 80 м). Суммарный объём 66 МБ.

## Что внутри каждого файла

- `id<N>_did.gpkg` — слой **windthrow** (Polygon, поле `area_ha`): связные объекты детекции после адаптивного порога (a=0.25 по медиане кадра), медианного фильтра 3×3 и отсечения объектов < 6 пикселей. Детекции покрывают весь кадр продукта HyP3, а не только полигон эталона — метрики (AUC/excess) считаются отдельно против полигонов Шихова–Эрлиха (кольцо 10 км). Варианты фона v0/v1/v2 меняют только фон выборки для метрик; сами детекции (GPKG, dcoh, mask) — единый выход детектора.

## Пары гранул и метрики

Полные метрики (AUC/excess/TPR@FPR5% по вариантам фона v0/v1/v2), имена пар гранул prepost/control и размеры фоновой выборки — в `results/gfw_rescore_results.json` (репозиторий nadiopt-cell/sar_windthrow) и в отчёте изд.8 (табл. 9).

## Как читать слой

1. Открывать в QGIS как векторный слой (GPKG, слой `windthrow`).
2. Достоверная часть следа — объекты, пересекающие эталонный полигон события; вне эталона это кандидаты/шум, среди них есть и реальные повреждения вне базы Шихова.
3. Вырожденные случаи: ID654 (полигон безлесный на дату события — детекции не относятся к ветровалу) и ID696 (след 222 м < 3 пикселей сетки — сигнал ниже случайности).
