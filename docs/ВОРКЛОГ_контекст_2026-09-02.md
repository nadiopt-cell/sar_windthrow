## 1. Суть проекта

QGIS-плагин (Sentinel-1 Windthrow Detector) для быстрого картирования ветровалов по SAR:
метод Rüetschi et al. 2019 (Remote Sensing 11(2):115) — индекс **WI = ΔVV + ΔVH**
(рост обратного рассеяния после шторма = ветровал), **адаптивный порог x̄(WI) + 2,9 дБ**,
медианные мульти-temporal композиты (≥5 pre-сцен), объектный фильтр n ≥ 27 px,
медианный фильтр 3×3, векторизация в GPKG с area_ha.

Тест на реальном событии: **ID666** из БД Shikhov et al. 2020 (ESSD 12:3489-3513) —
шквал 29.07–02.08.2017, 553 эталонных полигона, 9,5 км² ≈ **950 га**, направление SW-NE.

Ниша: в РФ ветровалы картируют только оптикой (Shikhov 2020 Landsat, Kanev 2024 S2 U-Net,
Korznikov 2025 Pleiades CNN) — SAR-детекция не автоматизирована, это новизна проекта.

## 6. Спецификация v0.8 — normalize_background (для реимплементации)

**Согласованный API:**
```python
WindthrowDetector(
    threshold_mode="adaptive",   # или "fixed"
    a_db=2.9,                    # или fixed_threshold_db=3.0
    min_pixels=27,
    median_filter_size=3,
    normalize_background=True,   # НОВОЕ в v0.8, по умолчанию True
).detect_file(pre_paths, post_paths, output_base, analysis_mask_path)
```

**Алгоритм нормализации (внутри detect_file, до расчёта WI):**
1. Сцены уже в дБ, выровнены на общую сетку (ensure_aligned).
2. Для каждой поляризации (VV, VH) отдельно:
   `offset_pol = median(post_dB[фон] − pre_dB[фон])` по фоновым пикселям
   (analysis mask МИНУС полигоны эталона; для эксперимента — буфер 3 км вокруг ID666
   минус полигоны — решение 4).
3. `post_dB_norm = post_dB − offset_pol` (аддитивный сдвиг, радиометрическая
   нормализация фона к pre-сцене).
4. WI считается уже по нормализованной post: `WI = (VV_norm − VV_pre) + (VH_norm − VH_pre)`.
5. Выход: **`*_wi_norm.tif`** (WI после нормализации и медианного фильтра 3×3);
   при normalize_background=False — прежний `*_wi.tif`, поведение v0.7.0 байт-в-байт.
6. Диагностика: `offset_vv`, `offset_vh` — в атрибуты детектора и в JSON-отчёт.

**GUI:** чекбокс «Background normalization» в табе Windthrow Detection, по умолчанию ВКЛ.

**Тесты (+4 к 72):**
- синтетическая post со сдвигом +1,5 дБ → после нормализации фон WI ≈ 0;
- ветровальный блоб +4 дБ в post остаётся детектируемым после нормализации;
- normalize_background=False → результат идентичен v0.7.0 (регрессионный);
- при норме создаётся `*_wi_norm.tif`.

Текущее состояние кода (проверено 02.09): `__init__(threshold_mode="adaptive", a_db=2.9,
fixed_threshold_db=3.0, min_pixels=27, median_filter_size=3)`; normalize_background —
добавить пятым параметром. Функции: adaptive_threshold, filter_small_objects (scipy,
8-связность), median_filter_nan, ensure_aligned (gdal.Warp), build_median_composite,
rasterize_vector_mask, detect_file → *_wi.tif/_mask.tif/.gpkg.
