## 5. Этап 10 — почему C-диапазон не работает летом

- Признаки: ΔVV, ΔVH, WI, отношения, лог-разности; окна post +1…+28 дн → **AUC 0.487–0.539** (случайное = 0.5).
- UA 1.5–2.3 % устойчивы к сетке a∈{2.5, 2.9, 3.3} дБ → причина фундаментальная, не параметрическая.
- Физика: C (5.6 см) отражается от кроны; летний фон нестационарен; метод Rüetschi 2019 создан для листопадных условий.
- Зима для ID666/ID694 непроверяема: события в вегетационный период; снег/мёрзлость дают 2–5 дБ > порога 2.9 дБ.
- JSON этапа утерян, числа восстановлены из сводки сессии.

## 6. Этапы 11b/11c — L-диапазон (ALOS PALSAR / PALSAR-2)

Физика инверсии (Tanase 2018): вывал = исчезновение объёмного рассеяния крон → HH/HV **падают** → метрики invAUC + порог Юдена + TPR@FPR5 %.

| Событие | Признак | invAUC | Примечание |
|---|---|---|---|
| ID666 | dHH | **0.870** | лучший на ID666 |
| ID666 | dHV | 0.732 | |
| ID694 | диапазон вариантов | **0.733–0.905** | верхняя граница — с маской ESA WorldCover 2020 |

- Впервые применён модуль `forest_mask` (маска → gdal.Warp к сетке → очистка фоновой выборки + ограничение детекции). Рост 0.733→0.905 подтверждает: чистота фона не менее важна, чем признак.
- Ранжирование устойчиво на обоих событиях: dHH > dHV; маска даёт сопоставимый выигрыш.
- Ограничения: PALSAR отключён 2011; для 2017 — PALSAR-2 по научной лицензии JAXA; перспективы — NISAR, ROSE-L.
- Скрипты и JSON этапов утеряны при откате; числа — из сводки сессии.
