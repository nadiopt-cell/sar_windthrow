# SAR Windthrow Detector (Sentinel-1 C-band + ALOS PALSAR L-band)

QGIS-плагин и исследовательский пайплайн для картирования ветровалов (сплошных вывалов леса бурями,
шквалами и торнадо) по бистемпоральным SAR-снимкам. Базовый метод — индекс ветровала
WI = ΔVV + ΔVH с адаптивным порогом x̄ + 2,9 дБ (Rüetschi et al. 2019); по ходу проекта конвейер
расширен до мультисенсорного: **L-диапазон ALOS PALSAR** и **интерферометрическая когерентность
C-диапазона** (ASF HyP3 INSAR-GAMMA) как альтернативные признаки детекции.

**Статус:** плагин **v1.0.0** (127/127 тестов) — три режима детекции: WI (C-band), `lband_decline`
(PALSAR LDI) и `coh_delta` (DiD по когерентности HyP3). Исследовательские этапы 7–12c закрыты:
амплитудный C-диапазон — обоснованный отрицательный результат; L-диапазон — invAUC до **0,905**;
когерентность с DiD — **7 событий, средний AUC 0,690 против 0,642 у одиночной пары**, максимум
**0,908** (ID694); до-до контроль для ID666 выполнен — улучшения не дал (фон внутри следа derecho
загрязнён в любой паре). Итоговый отчёт — **издание 3** (17 стр.) в `reports/`.

## Сенсоры и данные (проект уже не «только про Sentinel-1»)

| Данные | Диапазон/тип | Роль в проекте | Источник |
|---|---|---|---|
| Sentinel-1 RTC | C, VV/VH, γ⁰ 10 м | основной детекционный тракт плагина (индекс WI) | Microsoft Planetary Computer (STAC, sentinel-1-rtc) |
| Sentinel-1 SLC → когерентность | C, INSAR-GAMMA 20×4, шаг 80 м | пары «до/после» + пост-пост контроли; DiD-метрика | ASF HyP3 (авторизация Earthdata JWT) |
| ALOS / ALOS-2 PALSAR(-2) | L, HH/HV | валидированный признак с инверсным знаком (вывал = падение HH/HV) | мозаики PC (alos-palsar-mosaic), слайды K&C F02DAR |
| ESA WorldCover 2020 | оптическая классификация | маска леса: фоновая выборка + фильтр выходной маски | PC STAC, встроена в плагин v0.9.0 |
| Shikhov et al. 2020 (ESSD) | векторный эталон | полигоны ветровалов Европейской России 1986–2017 | CSV в `data/shikhov_csv/` |

> Ресурсы HyP3 (тариф Basic): 8000 кредитов/мес бесплатно, обновление ежемесячное;
> INSAR-GAMMA 80 м = 10 кредитов/пара (остаток 7810 после 19 пар этапов 12b/12c ≈ 781 пара);
> burst-пары 1–4 шт. = 1 кредит; платное пополнение — HyP3+ ($0,05/кредит). Плагину HyP3 не
> требуется — только модулю `coh_delta`; продукты HyP3 истекают (наши — 17.09/начало 10.2026),
> всё скачано заранее (~4,5 ГБ локально).

## Метод (плагин, v1.0.0)

1. **Источники:** Sentinel-1 GRD/RTC через STAC Microsoft Planetary Computer, загрузка COG-полос (VV/VH) по AOI.
2. **Препроцессинг:** пересчёт в дБ, фильтр спекл-шума Ли, маска суша/вода, пересчёт на единую сетку 10 м.
3. **Композиты:** медианные мозаики pre (стек из нескольких сцен до события) и post.
4. **Индекс ветровала:** WI = ΔVV + ΔVH (дБ), где Δ = post − pre.
5. **Порог:** адаптивный `x̄ + a дБ` (по умолчанию a = 2,9, как в Rüetschi et al. 2019) либо фиксированный; опциональная **нормализация фона** (вычитание медианного погодного сдвига post−pre по лесному фону).
6. **Маска леса (v0.9.0):** ESA WorldCover 2020 через PC STAC → gdal.Warp на сетку AOI; применяется дважды — к фоновой выборке и к фильтру выходной маски.
7. **Постобработка:** медианный фильтр 3×3, отбор связных объектов ≥ min_pixels (27 px = 0,27 га), векторизация в GeoPackage с площадью объектов в гектарах.

## Установка плагина

QGIS → Модули → **Установить из ZIP** → `plugin_dist/sentinel1_windthrow_plugin_v1.0.0.zip`.
Требуется QGIS ≥ 3.28. Вкладка «Ветровал»: AOI (прямоугольник на карте), даты pre/post, режим
порога, нормализация фона, маска леса, **селектор метода детекции** (WI / L-band LDI / когерентность
DiD; для когерентности — группа HyP3: загрузка SLC-пар, контролей и SANE-проверка water-маски).
Основной источник снимков — Sentinel-1 RTC на Planetary Computer.

## Ключевые результаты (этапы 7–12c)

Эксперименты выполнены на эталоне **Шихов и др. 2020** (ESSD, ~1400 событий 1986–2017). Тестовые
события: **ID666** — шквал 29.07–02.08.2017, Республика Коми (950 га); **ID694** — торнадо
19.09.2017, Пермский край (161 га).

| Эксперимент | Данные | Событие / сезон | Ключевая метрика | Вывод |
|---|---|---|---|---|
| step7 | S1 RTC (C) | ID666, лето | PA ≤ 0,137; UA 0,015–0,023 | сигнала нет: влажный фон растёт сильнее завала (контраст WI −1,0 дБ) |
| step8 | S1 RTC (C) | ID694/ID666, листопад | ΔWI +0,01…+0,02 дБ | листопадная путаница на 2 порядка ниже порога 2,9 дБ |
| step9 | WorldCover (v0.9.0) | ID666, лето | UA +15 % отн., FP-площадь −19 % | маска леса обязательна и встроена в плагин |
| step10 | S1 RTC (C), 8 индексов | оба события | AUC ≤ 0,577 везде | линейная семья C-band исчерпана; WI уже оптимален |
| step11b | **PALSAR (L)** | ID666, лето | invAUC **0,870** (dHH) | L-band решает: инверсный знак (вывал = падение сигнала) |
| step11c | **PALSAR (L)** + маска | ID694, сентябрь | invAUC **0,733–0,905** | лучший результат проекта; маска критична |
| step12b | **когерентность C** (HyP3) | оба события | prepost AUC 0,650–0,704; **DiD AUC 0,671 / 0,908** | парная разность с контролем выводит C-band на уровень L-band (ID694) |
| step12c | **когерентность C** (HyP3) | **7 событий** + до-до ID666 | DiD AUC 0,51–0,91, среднее **0,690** (raw 0,642); до-до для ID666 — 0,609 (не улучшает) | DiD устойчиво > 0,5; выигрыш максимальный при чистом фоне и близком по сезону контроле |

Дополнительные выводы: адаптивный порог математически инвариантен к аддитивной нормализации фона
(она полезна только с фиксированным порогом — режим мониторинга); стек из 3 pre-сцен снижает
площадь ложных срабатываний на 20–25 %; главные ложные тревоги — поля и вырубки. Для когерентности:
одиночная пара сильно зависит от сезона (осенняя инверсия: открытый настил когерентнее кроны,
AUC контроля 0,117), поэтому рабочая метрика — разность разностей DiD = coh(контроль) − coh(«до/после»);
фон очищается от ВСЕХ полигонов эталонной БД (для ID666 исключено 561 часть соседних завалов того же
derecho); water mask одного из продуктов HyP3 повреждена (99,6 % «воды») — применяется эвристика
sane-mask.

**Итоговый вывод:** амплитудный C-диапазон S1 (10 м RTC) не детектирует уральские ветровалы ни
летом, ни в листопад при любом линейном индексе. Подтверждённые рабочие пути: (1) **L-диапазон
PALSAR** — инверсная детекция с маской леса (invAUC 0,87–0,905); (2) **когерентность C-диапазона
через HyP3 INSAR-GAMMA с DiD-метрикой** — на 7 событиях средний AUC 0,690 против 0,642 у одиночной
пары, все 7 DiD > 0,5 (максимум 0,908 ID694; 0,764 ID674; 0,701 ID655). Границы метода установлены
step12c: (а) след derecho загрязняет фон в ЛЮБОЙ паре — до-до контроль для ID666 даёт лишь 0,609;
(б) сезонный скачок между окнами (жара июля 2015) гасит DiD; (в) узкие торнадо-треки (< ширины пикселя
80 м) размываются. Оба признака интегрированы в плагин v1.0 (режимы `lband_decline` и `coh_delta`).
