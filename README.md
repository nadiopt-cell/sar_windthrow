# Sentinel-1 Windthrow Detector

QGIS-плагин и исследовательский пайплайн для картирования ветровалов (вывалов леса бурями и шквалами) по бистемпоральным снимкам Sentinel-1 SAR с использованием индекса ветровала WI = ΔVV + ΔVH (метод Rüetschi et al. 2019).

**Статус:** плагин v0.8.0 (experimental), пайплайн детекции отработан end-to-end; проведены диагностические эксперименты step7 (лист-он) и step8 (лист-офф) на эталонных событиях из БД Шихова и др. (2020).

---

## Метод

1. **Источники:** Sentinel-1 GRD/RTC через STAC Microsoft Planetary Computer, загрузка COG-полос (VV/VH) по AOI.
2. **Препроцессинг:** пересчёт в дБ, фильтр спекл-шума Ли, маска суша/вода, пересчёт на единую сетку 10 м.
3. **Композиты:** медианные мозаики pre (стек из нескольких сцен до события) и post.
4. **Индекс ветровала:** WI = ΔVV + ΔVH (дБ), где Δ = post − pre.
5. **Порог:** адаптивный `x̄ + a дБ` (по умолчанию a = 2,9, как в Rüetschi et al. 2019) либо фиксированный; опциональная **нормализация фона** v0.8 (вычитание медианного погодного сдвига post−pre по лесному фону).
6. **Постобработка:** медианный фильтр 3×3, отбор связных объектов ≥ min_pixels (27 px = 0,27 га), векторизация в GeoPackage с площадью объектов в гектарах.

## Установка плагина

QGIS → Модули → **Установить из ZIP** → `plugin_dist/sentinel1_windthrow_plugin_v0.8.0.zip`. 
Требуется QGIS ≥ 3.28. Модуль экспериментальный: вкладка «Ветровал» позволяет выбрать AOI (прямоугольник на карте), даты pre/post, режим порога и нормализацию фона; источники — Sentinel-1 RTC/GRD на Planetary Computer.

## Ключевые результаты экспериментов

Эксперименты выполнены на эталоне **Шихов и др. 2020** (ESSD: ветровалы Европейской России, ~1400 событий 1986–2017). Кратко:

| Эксперимент | Событие | Сезон | Контраст WI (эталон − фон) | Вывод |
|---|---|---|---|---|
| step7, ID666 | шквал 29.07–02.08.2017, ~950 га | лист-он | **−1,0 дБ** | сигнала нет: влажный фон леса растёт сильнее повреждённого древостоя |
| step8, ID694 | торнадо ~19.09.2017, 161 га | лист-офф | +0,021…+0,024 дБ | сигнала нет против порога 2,9 дБ |
| step8, ID6660 | ID666, межгодовой октябрь (2016→2017) | лист-офф | +0,012…+0,017 дБ | сигнала нет; октябрьский погодный сдвиг +0,7 дБ снимается нормализацией |
| step9, ID666 | лесная маска WorldCover 2020 (v0.9) | лист-он | PA без изменений; UA +13–15 % отн. | поля уходят: площадь FP −19…−40 %; остаточный шум — мелкие объекты внутри леса |

Дополнительные выводы step7: адаптивный порог математически инвариантен к аддитивной нормализации фона (она полезна только с фиксированным порогом — режим мониторинга); стек из 3 pre-сцен снижает площадь ложных срабатываний на 20–25 %; главные ложные тревоги — поля и вырубки (UA 0,015–0,023), т.е. **лесная маска обязательна**.

**Итоговый вывод:** C-диапазон S1 RTC 10 м не детектирует уральские ветровалы ни в лист-он, ни в лист-офф; метод Рюэши (Альпы, PA 0,85–0,88) напрямую на смешанные леса Урала не переносится. Направления: ~~лесная маска~~ (готово в v0.9.0: WorldCover через STAC, UA +13–15 % отн., FP-площадь −40 %), студия индексов (dVH, VH/VV, log-ratio), L-band (PALSAR-2 / ROSA-L), для событий 2015 г. — тракт GRD+SNAP.
