# Release notes — Sentinel-1 Windthrow Detector v0.8.0

Дата: 02.09.2026

## Новое: фоновая нормализация (background normalization)

**Мотивация.** Тестирование на событии ID666 (шквал 29.07–02.08.2017,
БД Shikhov et al. 2020 ESSD) показало классический отказ режима
Rüetschi: «мокрый» погодный сдвиг ~+1 дБ между acquiring (дождь после
шторма, рост влажности почвы) поднимал весь фон post-сцены, среднее WI
уползало вверх и карта детекции заливалась ложными срабатываниями.

**Решение.** Новый параметр `WindthrowDetector(normalize_background=True)`
(по умолчанию ВКЛ). До вычисления WI из post-сцены вычитается
по-поляризационный аддитивный сдвиг:

```
offset_pol = median(post_dB − pre_dB)   по фоновой выборке (VV и VH отдельно)
post_dB_norm = post_dB − offset_pol
WI = (VV_norm − VV_pre) + (VH_norm − VH_pre)
```

Фоновая выборка задаётся `detect_file(..., background_mask_path=...)`
(рекомендуется: лесной фон ЗА пределами эталонного ветровала — напр.
буфер 3 км вокруг события минус сами полигоны); при отсутствии —
analysis mask, при отсутствии и её — вся сцена. Тот же образец
используется для среднего WI адаптивного порога.

**API-изменения.**
- `WindthrowDetector.__init__(..., normalize_background: bool = True)`.
- `detect_file(..., background_mask_path: Optional[str] = None)`.
- Диагностика: `detector.offset_db` ({"VV": ..., "VH": ...}), ключи
  отчёта `offset_db` и `normalize_background`.
- При включённой нормализации WI-растер пишется как
  `<base>_wi_norm.tif` (вместо `<base>_wi.tif`); маска/вектор — без
  изменений. `normalize_background=False` даёт поведение v0.7.0.

**GUI.** Чекбокс «Background normalization (remove weather shift)» в
табе Windthrow Detection, по умолчанию включён.

**Совместимость.** Регрессионный тест фиксирует идентичность
`normalize_background=False` поведению v0.7.0.

## Тесты

- 72 прежних + 4 новых (unit `background_offset_db`; сквозной прогон со
  сдвигом +1,5 дБ: offset восстанавливается, фон центрируется на ~0 дБ,
  блоб ветровала +8 дБ детектируется; регрессия norm=False; фоновая
  маска исключает ветровал из статистики, но не из детекции).
- Итого **76 passed** (Python 3.13, GDAL 3.10.3, numpy 2.2, scipy 1.18).

## Известные ограничения

- Нормализация убирает только однородный (аддитивный в дБ) сдвиг;
  пространственно-неоднородные изменения влажности не компенсируются —
  от них по-прежнему страхует лесная маска.
- Фоновая маска пока недоступна из GUI (передавайте через API/скрипт);
  GUI-поле запланировано на v0.9 вместе с глобальной лесной маской.
