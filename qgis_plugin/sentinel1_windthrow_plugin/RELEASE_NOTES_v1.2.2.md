# Release Notes — Sentinel-1 Windthrow Detector v1.2.2

Дата: 30.09.2026. Предыдущая версия: 1.2.1. Новая функциональность
когерентного режима; логика детекции и пороги не менялись.

## Новое: предохранитель «вне_леса@Y» в режиме Coherence DiD

Закрывает расхождение между статьёй (§границы метода + §«дальнейшие
шаги», случай ID654) и кодом: в тексте статьи утверждалось, что
«при доле леса GFC@Y ниже 0,3 плагин выставляет флаг вне_леса@Y», и
обещался предохранитель по когерентности pre-сцены выше 0,6 («кандидат
v1.2.2») — ни того, ни другого в v1.2.1 не было. Ссылка на статью
дана в настоящем времени, поэтому реализована именно функциональность,
а не правка текста.

**Физика (урок ID654).** Объект, не являющийся лесом на дату события,
не может быть детектирован когерентностью в принципе: вырубка внутри
года держит когерентность damage-пары на 0,635 (сигнатура голого
грунта), скоринг по «современным» картам растительности при этом
по-прежнему говорит «лес»; событие вырождается (AUC 0.051, инверсия
excess −0,396). До v1.2.2 плагин в такой ситуации молча возвращал
пустую/инвертированную детекцию.

**Реализация** (`sources/coh_delta.py`, `CoherenceDeltaDetector`):
две проверки по данным, которые прогон и так загружает, — без
дополнительных чтений растров и сети:

1. Средняя когерентность pre/post-пары внутри зоны (зона = маска
   анализа «внутри полигона», иначе фоновая лесная маска, иначе вся
   сцена) выше **0,6** → сигнатура безлесного состояния до шторма.
2. Доля леса в сцене (по фоновой маске чистого леса@Y, иначе по маске
   анализа) ниже **0,3** → зона вне предела применимости.

Прогон **не прерывается**: флаг пишется в лог (warning), в
`result["forest_safeguard"]` (`flagged`, `flags`, `reasons`, `zone`,
`coh_prepost_mean`, `forest_share`) и показывается крупным блоком
⚠ в окне результата GUI. Пороги — числа статьи, не тюнинговались.
Оговорки интерпретации (сценовая зона без масок размывает проверку
когерентности; файловая AOI-маска измеряет своё покрытие, а не
лесистость) задокументированы в METHOD.md §7b.

## Тесты (144 → 150)

`tests/test_coh_delta.py`, новый блок «v1.2.2: forest safeguard»:
константы совпадают с числами статьи; флаг по когерентности 0,7 в
зоне (ID654-кейс, доля 0,5 — проверка доли не срабатывает); флаг по
доле леса 0,2 при здоровой когерентности в лесной зоне; здоровый лес
с полной маской — без флага, детекция блоба сохраняется; зонная
семантика («analysis»/«background»/«scene»), `forest_share = None`
без масок; доля из маски анализа при отсутствии фоновой.

## Совместимость

интерфейс `detect_file` не изменился. QGIS ≥ 3.28, зависимости прежние
(numpy, scipy, GDAL).
