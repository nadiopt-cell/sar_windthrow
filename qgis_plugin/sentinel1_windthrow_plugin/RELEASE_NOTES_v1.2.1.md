# Release Notes — Sentinel-1 Windthrow Detector v1.2.1

Дата: 06.09.2026. Предыдущая версия: 1.2.0. Исправление GUI, логика
детекции не менялась.

## Исправление: источник маски леса в режиме Coherence DiD

Найден при подготовке пошаговой инструкции к реальному тестированию.

**Симптом.** В режиме когерентности (Coherence DiD) комбобокс
«Mask source» принудительно сбрасывался в «Custom file» и целиком
отключался. Валидированный воркфлоу **coh_delta + GFW GFC@Y** (обе
маски `_forest_gfc<Y>.tif` / `_forestbg_gfc<Y>.tif` на сетке DiD,
фон = чистый лес года, предшествующего событию; средний DiD-AUC 0.690
в отчёте изд.9) был из GUI недостижим — пользователь мог подать только
файловую маску, хотя код построения GFC/WorldCover-масок на сетке DiD
в `_run_coh_detection` присутствовал с v1.1.

**Причина.** Рудимент логики v1.0 в `_sync_method_widgets`:
комбо отключалось во «внерадарных» режимах с принудительным сбросом
в «Custom file», а жёстко зашитый индекс элемента `wc_index = 1`
(в v0.9/v1.0 это был WorldCover) после вставки источника GFC в v1.1
стал указывать на элемент GFC, а не WorldCover.

**Исправление.** Комбобокс «Mask source» доступен во всех трёх режимах;
все три источника (Custom file / GFW Hansen GFC / ESA WorldCover)
корректны для Coherence DiD — маски строятся на сетке DiD по
`ref_info` корреляционного слоя pre/post-продукта. Кнопка года «GFC
event year (Y)» активируется как прежде при выборе GFC.

## Проверка

  фикс верифицирован разбором кода: все ветки `_run_coh_detection`
  для `mask_source` в `("file", "worldcover", "gfc")` достижимы).

  затронуты (изменён один метод синхронизации виджетов).
