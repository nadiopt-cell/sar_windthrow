## Пересборка

Версия v2 собирается из исходников `build/` бит-в-бит (проверено: `word/document.xml`
идентичен мастеру, 298 109 байт):

```bash
cd article/build
npm install docx        # если docx-js ещё не установлен
node build.js           # -> ../Статья_..._v2_правки_A-E.docx
python3 diff_check.py           # QA: диф оригинал vs v2 по абзацам
python3 extract_morphology.py   # QA: ширины/зазоры из БД Шихова + Спирмен
```

Скрипты `build/` используют пути относительно репозитория (`../../data`,
`../../results`), работают из любой копии клона.

## Правки A–E (15 позиций)

1. **C1/C3** — новый раздел 3.2 «Морфология следов и разделимость» + новая таблица 2
   (ширина без/с зазорами, доля зазоров, GFC-потеря, AUC — 12 событий);
   Спирмен ρ(gaps, AUC): страта узких следов (181–222 м ≈ 2,3–2,8 px при сетке 80 м)
   ρ = −0,90 (n = 5); вся выборка ρ = −0,43 (n = 11); механизм — пара ID696/ID579
   (106 vs 107 эталонных пикселей, различие за счёт расчленённости)
2. **D1** — бимодальность AUC в 3.1: кластеры 0,749 / 0,536, медиана вместо среднего
3. **D1** — честность в обсуждении: AUC — порого-свободная метрика, несравнима
   напрямую с PA/UA протокола Rüetschi et al. 2019; автокорреляция эталонных выборок
4. **D3** — абзац о преимуществах SAR-DiD против оптических DL (Korznikov et al.,
   2025, NHESS nhess-2024-217: U-Net, Pléiades, 1490 км² Кунашира): независимость
   от облачности, теней/снега, чувствительность к массовому полому, оперативность,
   стоимость; двухслойный конвейер SAR-скрининг → оптическое картирование
5. **E2** — процессорная переносимость: DiD требует только геокодированные
   когерентность + амплитуду + водную маску (ISCE3/SNAP совместимы), контракт входа,
   адаптер в v1.3, оговорка о GAMMA-нормализации HyP3
6. **E3** — экономика: стандартные пары 10 кредитов vs burst-пары 1–4; квота 8000
   кредитов/мес; полный мониторинг сезона 5500–7800 кр ≈ 1 квота; событийная схема
   ≈ 5 % квоты; self-processing 100–300 CPU-ч
7. **D2** — объектные метрики IoU/F1 с буфером 1–2 px — в заключение/перспективы
8. **E** — предохранитель coh_pre > 0,6 → флаг «вне_леса@Y» (кандидат v1.2.2)
9. **D3** — leaf-off прогон когерентности (PA 0,059–0,116; UA 0,008–0,029)
10. **C3** — регрессия AUC vs геометрия дополнена долей зазоров
11. **C** — аннотация дополнена морфологическим результатом
12. Опечатка: «бркетируется» → «брекетируется»
13. Литература: [16] Korznikov et al. 2025 (введ. [15; 16]), Hansen GFC → [17],
    WorldCover → [18]; перенумерация ссылок
14. Благодарности: «Алжирский» → «Аляскинский центр»
15. Перенумерация таблиц 2→3 и 3→4 со всеми перекрёстными ссылками
